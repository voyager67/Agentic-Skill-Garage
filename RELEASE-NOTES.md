# Agentic Skill Garage 1.0.0

First standalone release. The repository contains 219 Apache-2.0 Agent Skills, a Python 3.10+ CLI, local reference and identity operations, optional image processing, ComfyUI request helpers, FFmpeg/FFprobe media operations, Blender headless helpers, a GitHub Pages showcase, and tests.

The demo uses synthetic inputs and displays real local CLI operations. It does not claim a live AI generation or paid provider call. Application-specific workflows require the corresponding application or service to be installed and configured.

The repository uses local-first defaults, explicit upload boundaries, sourced rate-card quotes, and no-overwrite file handling. See README.md, PRIVACY.md, SECURITY.md, NOTICE.md, and REFERENCES.md.
